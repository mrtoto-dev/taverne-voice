# Taverne Voice

Un changeur de voix pour Windows, pensé pour streamer sur Twitch et parler sur Discord : 33 voix, un soundboard avec Myinstants et des plugins pour les Stream Deck Elgato, Mars Gaming, Mirabox, Ajazz et Ulanzi.

**Site et guide : https://mrtoto-dev.github.io/taverne-voice/**

## Télécharger

Dans **[Releases](https://github.com/mrtoto-dev/taverne-voice/releases/latest)**, télécharge **`Taverne-Voice-Setup.exe`**.

Windows peut afficher « Windows a protégé votre ordinateur » : clique sur « Informations complémentaires », puis sur « Exécuter quand même ».

## Démo et version complète

La démo est gratuite et sans limite de temps : 5 voix et 3 sons. Une clé débloque les 33 voix, les réglages fins, un soundboard sans limite et les plugins Stream Deck. Voir [Version complète](https://mrtoto-dev.github.io/taverne-voice/licence.html).

## Aide

Le [guide](https://mrtoto-dev.github.io/taverne-voice/installation.html) explique l'installation, le branchement dans OBS et Discord, le soundboard et chaque Stream Deck. Les problèmes courants sont dans la [FAQ](https://mrtoto-dev.github.io/taverne-voice/faq.html).
